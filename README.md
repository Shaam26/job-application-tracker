# Job Application Tracker

A full-stack Job Application Tracker built with Spring Boot, PostgreSQL, and React. The application allows users to securely manage and track their job applications in one place.

## 🚀 Live Demo

[View Live Application](https://job-application-tracker-2y6s.onrender.com)

## 📌 Features

- User registration and login
- JWT-based authentication
- Secure password encryption using BCrypt
- Add job applications
- View job applications
- Edit existing applications
- Delete applications
- Track application status
- Store company, job role, application date, job link, and notes
- User-specific job application data
- Dashboard
- PostgreSQL database integration
- Responsive web interface
